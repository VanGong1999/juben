## 硬规则

1. **第 1–3 秒**必须交付：冲突 / 危险 / 指控 / 反转 / 欲望 / 冲击 / 不稳定情绪之一。
2. **尽量晚进戏**：砍掉热身说明，从最可表演的行动开拍。
3. **前 30 秒必须完成**：核心冲突或悬念 · 主角处境（弱势/困境/反差）· 第一个钩子。
4. **非第 1 集**：最多 5 秒回应上集悬念，立刻造新张力；每集开头都按第一集标准写。
5. 钩子要**具象落在前 3 个节拍内**（可被看见的动作/对白），不是标签。

## 禁止

- 大段旁白介绍背景
- 风景空镜、日常生活流水账
- 「从前有个人叫 xxx」式平铺
- 多角色同时出场导致信息过载
- 用解释性对白代替碰撞

## 6 种开场模板（择一）

| 模板 | 结构 | 适用 |
|------|------|------|
| 直接打脸 | 当众羞辱 → 施辱者嚣张 → 主角隐忍/暗藏身份 | 战神、逆袭 |
| 身份反转 | 低评价 → 立刻暗示真实身份碾压 | 霸总、萌宝 |
| 极端困境 | 绝境/死亡边缘 → 重生/穿越/觉醒 | 重生、悬疑 |
| 倒叙悬念 | 高潮片段闪回 → 拉回「N 天前」 | 悬疑、反转 |
| 强欲望 | 明确「要什么」+ 立刻受阻 | 甜宠、励志 |
| 危机打断 | 日常一拍 → 突发事件撕开平静 | 都市、家庭 |

## 单集形状（nolanx）

每条 clip / 每集：`hook → escalation → exit bridge`。  
中段若放松：加反应转折、打断、揭露或权力位移。优先可表演动词。
