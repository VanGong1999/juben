## 原则：剧本管戏，分镜管拍

本 skill 只管集 / 场 / 节拍 / 台词，不写镜号与生成提示词。

## 硬规则（质量门）

1. **节拍流**：动作节拍与台词行交替推进；不要写成无法喂 TTS/画面的散文块。
2. **每场至少一个动作节拍**：纯对白场 = 广播剧，竖屏短剧不合格。
3. **动作写常见可生成行为**（推门、摔杯、拦车、递文件）；少写精巧到生成必崩的微表情炫技。
4. **开场钩子具象**：全集前 3 个节拍内必须出现可被看见/听见的钩子。
5. **结尾悬念落纸**：最后一拍必须是悬念，不可「散会式」收束。
6. **爽点认领**：大纲标注的本集爽点，必须有场次/节拍接住。
7. **说话人合法**：台词角色必须在本场出场人物中（画外音标 VO）。

## 推荐场次骨架

```
△ 动作（进场/冲突触发）
角色A（语气）：「短台词」
△ 动作（反应/升级）
角色B（语气）：「短台词」
…
△ 动作（切断或兑现）
> 🎣 本集钩子：…
```

## 自检清单

- [ ] 有没有连续三段纯说明对白？
- [ ] 钩子是否出现在前 3 拍？
- [ ] 本集爽点是否被某场「认领」？
- [ ] 单句是否过长、需要拆句？
