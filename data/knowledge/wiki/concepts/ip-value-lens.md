# IP 价值评估透镜

## Summary
评估故事/小说 IP 是否值得改编短剧时，固定走四个透镜。

## 四透镜
1. **可改编性**：冲突是否可视化、节奏是否适合竖屏切片
2. **受众**：核心人群是否清晰、付费意愿
3. **系列化**：能否支撑 60–100 集钩子而不崩
4. **差异化**：相对同赛道爆款的不可替代点
