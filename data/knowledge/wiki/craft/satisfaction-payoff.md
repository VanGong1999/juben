## 五大爽点

### 1. 身份碾压
轻视 → 蓄力 → 揭露 → 碾压 → 跪地。  
子型：军衔 / 证件 / 一通电话 / 财富 / 能力 / 大人物示好。  
要点：受辱够狠；揭露有仪式感；写围观者。

### 2. 打脸复仇
被欺 → 隐忍 → 反击 → 当众出丑。  
子型：原话奉还 / 证据反杀 / 局中局 / 以牙还牙 / 群众审判。  
要点：反派先前嚣张要记得住；主角打脸时越冷静越爽。

### 3. 逆袭翻盘
谷底 → 绝望 → 转机 → 逐步翻盘。  
要点：谷底够低；转机有伏笔；翻盘分步，虐过主角的人必须亲眼看见。

### 4. 情感爆发
压抑/误会 → 极限 → 告白/冰释/重逢。  
子型：告白、真相、误会冰释、久别重逢、牺牲揭露、崩溃哭诉。

### 5. 智斗破局
信息差 → 误判 → 关键证据/布局亮出 → 局势翻转。  
适用于悬疑、商战、宫斗；爽点在「原来你早算到了」。

## 强度分级（投放用）

| 星级 | 用途 |
|------|------|
| ★★ | 日常推进集小满足 |
| ★★★ | 中段记忆点 |
| ★★★★ | 🔥 关键剧情集 |
| ★★★★★ | 全剧级终极兑现（少用） |

## 配比建议

- 前 10 集：至少 3 个 ≥★★★ 爽点，类型尽量不重复
- 全剧避免连续 3 集同一爽点子型
- 男频偏 1+2+3；女频偏 4+2+1；悬疑偏 5+2
